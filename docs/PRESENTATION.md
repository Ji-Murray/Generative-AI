# LectureQA 答辩提纲

建议时长：5–7 分钟。将四位成员姓名填入最后一页和 `docs/CHECKLIST.md`。

## 1. 问题（40 秒）

课程复习中，学生需要知道答案是否来自讲义、依据在哪一页，以及讲义没有覆盖时系统是否会明确说明。直接使用通用模型容易得到流畅答案，却难以确认来源。

## 2. 产品定位（40 秒）

LectureQA 是一个来源可控的课程复习助手。它提供讲义问答、正文内页码跳转、讲义范围外拒答、可选的网络补充、可溯源 Quiz 和学习进度。

一句话：通用模型擅长解释，LectureQA 擅长让复习答案可核对、来源可分清。

## 3. 核心流程（60 秒）

```text
PDF → 按页切分 → 向量 + BM25 检索 → 证据充分性判断
    → 带引用生成 → 引用校验 → 页码跳转 / Quiz / 学习记录
```

关键设计：按页切分保证引用落在具体页面；生成前检查证据；生成后删除不在证据集中的引用；网络补充与讲义答案分开展示。

## 4. 产品演示（2 分钟）

1. 提问一个讲义明确覆盖的问题，展示答案正文中的 `p.N` 页码。
2. 点击页码，展示右侧课件跳转到对应页面，并展开原文片段。
3. 提问一个讲义未覆盖的问题，展示仅讲义模式的拒答。
4. 打开网络补充模式，展示外部来源与讲义来源分开标注。
5. 进入 Quiz，展示题目、答案和出处。

## 5. 实验结果（90 秒）

正式测试集包含 72 题，其中可答 62 题、不可答 10 题，覆盖 10 份讲义。

| 指标 | Hybrid + coverage | BM25-only |
|---|---:|---:|
| hit@6 | 0.919 | 0.677 |
| recall@6 | 0.887 | 0.653 |
| MRR | 0.749 | 0.504 |
| citation precision | 0.677 | 0.505 |
| grounded rate | 0.790 | 0.548 |

Hybrid 相比 BM25-only 的 hit 提升 24.2 个百分点，grounded rate 提升 25.8 个百分点。不可答题拒答率为 90%（9/10）；报告同时记录了 1 个拒答漏判，避免把结果表述成 100%。

交叉编码器重排的 citation precision 为 0.703、grounded rate 为 0.855，但增加额外模型依赖，因此默认使用轻量 coverage 重排。

## 6. 局限与下一步（40 秒）

当前主要局限是引用精度仍有提升空间、部分可答题被保守拒答、扫描 PDF 的 OCR 和图表理解有限。用户研究协议已经准备好，实际采样需要人工完成；全量 LLM-as-judge 需要当前账号有权限访问的 judge 模型。

## 7. 分工（20 秒）

| 成员 | 工作 |
|---|---|
| A：姓名 | PDF 解析、分块、向量库、检索 |
| B：姓名 | 生成提示、引用约束、Quiz |
| C：姓名 | Streamlit、页码跳转、系统集成 |
| D：姓名 | 测试集、消融实验、报告 |

## 答辩时的核心表述

> 我们没有把目标定义成比通用模型更全能，而是针对课程复习增加了来源约束：答案必须能回到讲义页面，讲义没有覆盖时要拒答，网络补充要单独标注，练习题也要有出处。正式评估显示，混合检索相对 BM25-only 明显提高了页面召回和答案 grounded rate。
