# 03 · 生成与引用

> 里程碑：`RetrievedChunk[]` → 有引用的回答 / 可解释拒答。

## 本轮要实现

1. `llm.py`：OpenAI 兼容 chat completions、超时、重试、JSON 修复、FakeLLM。
2. `generation/prompts.py`：提示词唯一集中位置；证据块 label 含 `doc_id` 和页码。
3. `generation/qa.py`：先做证据阈值判断，低于阈值不调用模型；模型只能基于 evidence 回答。
4. 引用解析器：识别 `[[doc_id:pN]]`，只允许命中本次检索证据的页码；无效引用剔除并记录。
5. `/ask`、`/ask/stream`、CLI `ask`、Streamlit chat 接入。

## 约束

- `NO_ANSWER` 是模型拒答哨兵；用户端不得直接看到哨兵字符串。
- 每条 `Citation` 都带原文 snippet，便于核验。
- `grounded` 的定义是至少存在一条有效引用，不把“模型声称有依据”当成接地。
- 未配置 LLM Key 时应尽早清晰报错，检索能力仍可单独使用。

## 验收命令

```bash
lectureqa ask "多头注意力为什么要使用缩放因子？"
python -m pytest tests/test_citation.py tests/test_qa.py -q
```

通过标准：正常答案引用页码可回查；编造 doc/page 被删；支持度低时 FakeLLM 调用次数为 0。
