# 02 · 检索管线

> 里程碑：问题 → 混合召回 → RRF → 重排 → `RetrievedChunk[]`。

## 本轮要实现

1. `textutils.py`：中英混排 tokenization（拉丁词 + CJK 字 / 二元组），复用常量与函数。
2. `retrieval/embeddings.py`：`Embedder` 协议及 openai/hash/chroma 三种 provider。
3. `retrieval/store.py`：`VectorStore` 协议，Chroma 持久化默认，Local/numpy 兜底。
4. `retrieval/bm25.py`：BM25 自实现，支持 doc 过滤。
5. `retrieval/corpus.py`：chunks.jsonl 事实源 + BM25 缓存。
6. `retrieval/retriever.py`：dense + BM25，Reciprocal Rank Fusion，支持 `doc_ids` 过滤。
7. `retrieval/rerank.py`：coverage 默认重排，可选 cross-encoder。
8. `service.py` / `cli.py search` / API `POST /search` 接线。

## 约束

- 检索结果必须回查 Corpus 得到 `Chunk`，不能只返回向量库 metadata。
- 页面过滤后，dense 与 lexical 结果必须都满足 doc_ids。
- embedding 网络失败时平滑退化 BM25；记录日志，不吞掉错误静默假装向量可用。
- 离题结果 support=0 时剔除；避免 BM25 的低相关噪声进入生成。

## 验收命令

```bash
lectureqa ingest data/sample
lectureqa search "缩放点积注意力里的 sqrt(d_k) 起什么作用" --top-k 3
python -m pytest tests/test_retrieval.py -q
```

通过标准：精确术语的相关页排名第一；过滤 doc_id 后不出现其他讲义；离题问题不返回证据。
