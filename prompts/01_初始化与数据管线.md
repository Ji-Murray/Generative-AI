# 01 · 初始化与数据管线

> 里程碑：`data/*.pdf` → 页级文本 → 分块 → `chunks.jsonl` + 向量索引。

## 本轮要实现

1. 项目骨架：`pyproject.toml`（uv/pip 均可）、`.env.example`、`.gitignore`、`src/lectureqa/`。
2. `config.py`：所有参数从 `.env` 读取（pydantic-settings），代码里不出现魔法数字。
3. `schemas.py`：`Chunk` / `DocumentInfo` / `IngestReport` 等数据契约。
4. `ingest/pdf.py`：PyMuPDF 逐页抽取，**保留 1-based 页码**，猜测页标题。
5. `ingest/chunker.py`：**以页为不可跨越边界**分块，页内按句子打包 + 重叠；尾部碎片并入上一块。
6. `ingest/pipeline.py`：编排 + 写 `var/index/chunks.jsonl` 与 `manifest.json` + 建向量索引。
7. `cli.py` 的 `ingest` / `documents` 子命令。

## 约束

- `chunk_id` 必须形如 `{doc_id}:p{page}:c{idx}`，全局唯一。
- 扫描版 PDF 不要静默失败：进 `skipped` 并在报告里显示。
- 向量化失败不能让整个 ingest 失败（无 Key 时仍要能落到 BM25 可用的 chunks.jsonl）。

## 验收命令

```bash
lectureqa --help
lectureqa ingest data/sample        # 或用 data/ 里的真实讲义
lectureqa documents
python -m pytest tests/test_chunker.py tests/test_ingest.py -q
```

通过标准：`documents` 列出的讲义数与 PDF 数一致；`manifest.json` 里 `num_chunks > 0`；
任意两个 chunks 的 `chunk_id` 不重复；同一 chunk 内只出现一个 `page`。
