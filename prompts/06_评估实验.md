# 06 · 评估实验

> 里程碑：标注测试集 → 指标计算 → JSON/Markdown 报告。

## 本轮要实现

1. `eval/testset.*.jsonl`：一行一题，answerable + unanswerable 混合，严格按 `docs/EVALUATION.md` 标注。
2. `eval/metrics.py`：hit@k、recall@k、MRR、citation precision、grounded rate、refusal accuracy、latency。
3. `eval/runner.py`：逐题跑检索与问答，错误样本记录 `error` 并继续；报告落到 `eval/reports/`。
4. 可选 LLM-as-judge：只在配置 `EVAL_JUDGE_MODEL` 且 `--judge` 时使用；没有 Key 时不影响检索侧结果。
5. 固定消融组：BM25、hybrid + coverage、hybrid + cross-encoder；每次实验保存配置快照与结果。

## 约束

- `unanswerable` 样本不参与 recall/MRR/citation precision 分母，但参加拒答率统计。
- 出错样本应报告 error_rate，其他指标从分母排除，不能算作错误拒答。
- 每个正式实验先固定 testset 版本、`k` 与 `.env` 参数，避免不同配置不可比。
- sample 测试集只用于自测；正式报告必须扩充到覆盖全部讲义的人工标注集。

## 验收命令

```bash
lectureqa eval --testset eval/testset.sample.jsonl -k 6
python -m pytest tests/test_metrics.py tests/test_e2e.py -q
```

通过标准：错误样本不中断全局；报告同时包含指标汇总、逐题结果、配置和时间戳。
