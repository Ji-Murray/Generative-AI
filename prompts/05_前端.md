# 05 · 前端

> 里程碑：Streamlit 演示界面（问答 / Quiz / 检索调试）。

## 本轮要实现

1. `app/streamlit_app.py`：
   - 侧边栏：索引状态、构建/重建索引按钮、讲义多选 + top-k 滑块、环境信息；
   - 问答标签页：`st.chat_input` + 流式渲染 + 引用卡片（可展开看 snippet、点击打开 PDF 对应页）；
   - Quiz 标签页：主题/题数/难度/题型表单 → 题目卡片 + 答案折叠；
   - 检索调试标签页：召回片段表格（score/support/dense/bm25 分列）。
2. 状态缓存：`st.cache_resource` 缓存 service，重建索引后 `st.cache_resource.clear()`。
3. 明确的空态与错误态：无索引、无证据、接口失败都要有可读提示。

## 约束

- 前端不写业务逻辑：只调用 `LectureQAService`（与 API/CLI 同一条装配线）。
- 拒答必须显式视觉区分（警告样式），不能让用户误以为模型漏答。
- 出处卡片必须可回溯：显示 `chunk_id` 与 PDF 第 N 页链接。

## 验收命令

```bash
streamlit run app/streamlit_app.py
```

通过标准：无索引时点击“构建索引”能成功；提问能流式输出并显示引用；Quiz 能出题并展开答案。
